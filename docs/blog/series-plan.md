**시점** 7/6 ~ (이후 계속)

| | |
|---|---|
| 다룰 것 | **시리즈의 전환점.** 연결 방법 + 뭐가 달라졌는지 |
| 포인트 | AI가 플레이 모드를 켜고 **직접 측정**하기 시작 |
| 삽질 ① | `execute_code`는 CodeDom C#6 — `using` 불가, `UnityEngine.Object` 명시 필요 |
| 삽질 ② | 에디트 모드 `Instantiate`는 `Awake()`를 실행 안 함 → 지연 초기화 가드 필요 |
| 자료 | 검증 로그 다수 ✅ / 📸 플레이 모드 측정 장면 |

**실제 대화 예시 (그대로 인용 가능)**

```
나: "대시 중 무적인데 근접 적한테 쓰면 그냥 맞아"
AI: (플레이 모드 진입 → 스킬 발동 → 실드 상태 읽음)
    "무적이 0.35초인데 이동이 0.12초입니다.
     적 옆에 착지한 뒤 0.23초 만에 풀려서 접촉 피해를 맞습니다."
```

> 추측이 아니라 측정. 이 편의 핵심 메시지입니다.

## 8편 — 회고

| | |
|---|---|
| 다룰 것 | 5주 전과 지금 |
| 소재 ① | **"측정해봐"가 제일 강한 요청** — AI도 추측하면 틀림 |
| 소재 ② | **함정은 기록 안 하면 반드시 다시 밟음** → 문서보다 코드 주석 |
| 소재 ③ | **저장 키와 표시 이름 분리** — 이름 두 번 바꾸며 배움 |
| 자료 | ✍️ 대부분 직접 |

**남겨둘 만한 버그 하나 (여기 넣거나 3편에 넣거나)**

전체 화면에서만 UI가 겹쳤던 건:

```csharp
float scale = slot.lossyScale.y;             // 캔버스 배율이 이미 들어있음
panels[i].localScale = Vector3.one * scale;  // 부모도 같은 배율 → 제곱
```

| 캔버스 배율 | 실제 적용 |
|---|---|
| 1.0 (창) | 1.0 정상 |
| 1.5 (전체화면) | **2.25** 겹침 |

> 특정 조건에서만 터지는 버그는 대체로 그 조건에서만 1이 아닌 값이 곱해집니다.
