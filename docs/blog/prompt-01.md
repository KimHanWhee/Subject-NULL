> 아래 `---` 사이 전체를 복사해서 블로그 프로젝트에 붙여넣으세요.

---

게임 개발기 시리즈 1편을 써줘. 아래 자료는 전부 실제 git 기록과 당시 문서에서 뽑은 사실이야.

## 글의 전개

이 순서로 가고 싶어.

1. **이런 슈팅 게임을 만들고 싶어서 유튜브 영상을 찾음**
2. **영상 보고 기본적인 것들을 만들어봄** — 움직임, 공격, 적 생성
3. **나만의 게임을 만들려고 특이 기능을 계획함** — 대시 + 니어미스 슬로우모션 + 스펠 시스템

3번이 이 글의 목적지야. 1~2번은 거기까지 가는 과정으로 짧게.

## 배경

- 인생 첫 게임 개발
- Unity 6000.4.10f1 / C# / 2D 탑다운 슈팅
- 개발 기간 2026-06-27 ~ 07-31 (약 5주)
- 이 글은 첫 주(6/27 ~ 7/3) 이야기

## 내가 직접 채울 부분 (비워두거나 자리표시자로)

다음은 내 개인 경험이라 네가 지어내면 안 돼. `[여기에 …]` 형태로 자리만 만들어줘.

- 왜 게임을 만들려고 했는지 (그전 직업/경험 포함)
- Unity와 C#을 얼마나 알았는지
- 참고한 유튜브 영상 제목 / 채널 / 링크
- 따라 만드는 데 며칠 걸렸는지, 막힌 곳은 없었는지
- 처음 게임이 움직이는 걸 봤을 때 기분
- 왜 하필 "대시"와 "스펠"이었는지 (영향받은 게임이 있는지)

## [3] 계획을 적다 — 7월 3일

프로젝트에 문서를 만들고 넣고 싶은 기능을 적음. **아래는 그때 쓴 원문 그대로.**

```
1. 플레이어 대시 기능
- Space + 방향키 클릭 시 해당 방향으로 짧은 대시 스태미너 사용
  쿨타임 1초 (스테미너 추가 필요)
- 적의 원거리 공격 (총알, 화살, 레이저)를 아슬아슬하게 피했을 시,
  해당 오브젝트랑 플레이어의 거리가 특정 px 이하일때 대시로 피했을 시
  게임의 속도가 잠깐 슬로우 걸림

2. 스펠 마블
   플레이어가 사용가능한 특수 능력
   스페이드, 하트, 클로버, 다이아몬드로 타입이 나뉨
   ♠ 스페이드 = 공격
   ♥ 하트 = 회복
   ♣ 클로버 = 유틸/교란
   ♦ 다이아몬드 = 방어

- 플레이어는 사전에 스펠 마블 덱을 구성할 수 있음.
  개수는 대략 15~25개 예상중, MainScene에 덱 구성 씬이 추가되어야 함
- GameScene 우측 하단에 현재 사용 가능한 덱에 있는 스펠마블 5개의 타입이
  동그라미 다섯개에 표기됨
- ctrl 키를 클릭 시 우측 하단의 타입만 표기되던 동그라미 다섯개가
  조금 위로 올라오며 선택창이 뜸 (마우스 올릴시 상세 능력 확인 가능)
- ctrl을 클릭하여 스펠 마블을 고를때 선택 화면 제외 게임 속도 느려짐
- 스펠마블 드래그 앤 드랍 형식으로 사용가능
  특정위치에 능력을 발동 시킨다거나 플레이어 버프 스킬일 경우
  아무 곳에나 드롭해도 플레이어한테 적용되는 방식
- 스펠 마블의 등급이 존재함
  (일반(무색) -> 골드(금색) -> 다이아(푸른색) -> 레전드(무지개빛))
```

**이 계획에서 강조하고 싶은 것 두 가지:**

① **니어미스 슬로우모션.** 간신히 피한 것과 여유롭게 피한 것을 게임이 구분해서 알아봐 주는 장치. 기본 게임에는 "선택할 게 없다"는 문제가 있었는데, 이걸 정면으로 건드리는 기능이었음.

② **UI 동작까지 적어놨다는 점.** "동그라미 다섯 개가 조금 위로 올라오며" 같은 문장이 계획 단계에 이미 있었음.

# 작성 지침

**분량** 3,000~4,000자. 시리즈 1편이라 길지 않게.

**톤**
- 첫 게임을 만든 사람의 회고. 전문가 톤 금지
- 담담하게. "놀랍게도", "결국 해냈다" 같은 과장 금지
- 기술 설명은 최소로. ScriptableObject가 뭔지 같은 건 넣지 말 것 — 뒤 편에서 다룸

**구조**
- 소제목으로 나눠서
- 위 표(파일별 줄 수, 계획 대비 결과)는 그대로 살려줘. 숫자가 이 글의 뼈대야
- 계획 원문은 인용 블록으로 살리되, 전부 넣지 말고 핵심만 발췌해도 좋음

**하지 말 것**
- 내가 안 겪은 일을 지어내지 말 것
- "이때 나는 ~라고 생각했다" 식으로 내 심리를 창작하지 말 것 — 자리표시자로 남길 것
- 자료에 없는 기술적 사실을 추가하지 말 것

**마지막 문단**
2편 예고로 끝내줘. 2편은 "이걸 혼자 다 짤 수는 없어서 Claude Code에 코드를 맡기기 시작한 이야기".
