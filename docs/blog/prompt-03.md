# 3편 자료 — PixelLab 연동 (그림을 못 그려서)

> 무료 에셋으로 시작했다가, AI 도트 생성 도구를 붙여 적과 캐릭터를 전부 새로 만든 단계.

---

## 문제

그림을 못 그린다.

1편에서 유튜브를 보고 만들 때는 무료 에셋을 받아 썼다. 스프라이트 시트에 `Idle` `Talk` `Reload` `Run` `Shoot` `Death` 라고 **손글씨 라벨**이 붙어 있는 그런 에셋이다.

문제는 두 가지였다.

- 게임에 **컨셉이 생기니** 안 맞았다 (실험실에서 탈출한 실험체 이야기인데 캐릭터가 그냥 파란 병사)
- 적을 추가할 때마다 **화풍이 제각각**이 됐다. 여기저기서 받아 쓰니 톤이 안 맞는다

---

## PixelLab 연동

AI로 도트를 생성하는 서비스다. MCP로 붙는다.

```json
"pixellab": {
  "type": "http",
  "url": "https://api.pixellab.ai/mcp",
  "headers": { "Authorization": "Bearer <API 키>" }
}
```

Unity MCP처럼 로컬 브리지가 필요 없다. 그냥 원격 주소를 등록하면 끝. 구독제라 생성 횟수가 정해져 있다.

---

## 화풍을 맞추는 법 — `style_images`

이게 핵심이었다.

그냥 "슬라임 만들어줘"라고 하면 매번 다른 화풍이 나온다. **이미 있는 스프라이트를 참조로 넣으면** 그 톤에 맞춰 그려준다.

```
create_1_direction_object(
  description = "빛나는 코어를 가진 실험체 몬스터",
  view = "top-down",
  style_images = [<플레이어 스프라이트>]   ← 이게 핵심
)
```

플레이어 스프라이트를 참조로 넣고 적을 전부 다시 뽑았다. 그래서 7종이 한 세트로 보인다.

**만든 것** — 슬라임 / 탱크슬라임 / 박쥐 / 샷건박쥐 / 레이저박쥐 / 개구리 / 힐드론

컨셉은 전부 **"실험실 표본 몬스터"**. 빛나는 코어, 바이오테크 느낌.

---

## 실제 작업 순서

**① 생성** — 후보를 여러 개 받는다

```
create_1_direction_object(...)
  → get_object 로 후보 미리보기
  → select_object_frames(indices=[가장 나은 것])
```

**② 애니메이션**

```
animate_object(object_id, animation_description="이동 루프", frame_count=6)
```

**③ 시트로 합치기**

프레임이 낱장 이미지로 나온다. 이걸 가로로 이어 붙여 스프라이트 시트를 만든다.
결과: **448×64 = 64px 프레임 7장** (적 7종 모두 동일 규격)

**④ Unity 임포트**

- Sprite Mode = Multiple, 64×64로 슬라이스
- Filter = Point (도트가 뭉개지지 않게)
- 압축 없음

**⑤ 애니메이션 클립 재연결**

기존 클립의 프레임 참조만 새 스프라이트로 갈아끼운다. Idle / Run / Spawn.

## Aseprite와 나눠 쓰기

도트 도구를 하나 더 붙였다. **직접 그리는** 쪽이다.

경계가 명확했다.

|              | 잘 되는 것                   | 안 되는 것      |
| ------------ | ---------------------------- | --------------- |
| **PixelLab** | 일러스트급 아이콘, 큰 캐릭터 | 픽셀 단위 통제  |
| **Aseprite** | 16~20px 작은 스프라이트      | 정교한 일러스트 |

---

## UI도 뽑았다

`create_ui_asset`으로 패널·버튼 프레임을 만들었다.

만든 것: 덱/가챠 패널, 메인메뉴 버튼, 로그인 프롬프트 배경, 스태미너 게이지 틀

**함정:** 결과가 **여러 변형이 한 장에 담긴 시트**로 온다. 원하는 하나를 잘라 써야 한다.

그리고 UI 프레임은 **9-슬라이스**로 임포트해야 한다. 안 그러면 크기를 바꿀 때 모서리가 늘어나 뭉개진다.
